# Experiment summary

This repository keeps the standard standalone model experiments runnable for Logistic Regression, Random Forest, SVM, XGBoost, LightGBM, and CatBoost.

The final competition-side submission used an additional reference-aided method:
**Semi-supervised CatBoost distillation + confidence-gated post-processing**.

Known Kaggle public score for the final submitted version: **0.82160**.

The final pipeline uses a public reference submission as a teacher/reference signal. It is documented separately from the standalone model comparison so the final competition procedure is transparent and reproducible.
