# AI3023 Machine Learning Workshop — Spaceship Titanic

Binary classification project for Kaggle **Spaceship Titanic**: predict `Transported` for each passenger.

## Repository structure

```text
spaceship-titanic-mlw/
├── data/
├── src/
├── outputs/
├── figures/
├── submissions/   # optional; you can keep final hand-picked submissions here
├── README.md
└── requirements.txt
```

## Required data files

Place Kaggle files in `data/`:
- `data/train.csv`
- `data/test.csv`
- `data/sample_submission.csv` (recommended)

Optional LightGBM package:
- `data/spaceship_catboost_preprocessed_package.zip`
  or extracted folder `data/spaceship_catboost_preprocessed_package/`.

All scripts use **relative paths** from project root via `src/utils.py`.

## Environment setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run one model

```bash
python src/train_logistic_regression.py
python src/train_random_forest.py
python src/train_svm.py
python src/train_xgboost.py --make-submission
python src/train_lightgbm.py
```

## Run all models

```bash
python src/run_all.py
```

Fast smoke run (skips heavy tracks and reduces tuning):

```bash
python src/run_all.py --skip-heavy
```

`run_all.py` writes unified results to:
- `outputs/results_summary.csv`

## Generate model comparison

```bash
python src/compare_models.py
```

Outputs:
- `outputs/model_comparison_summary.csv`
- `figures/model_comparison_accuracy.png`
- `figures/model_comparison_training_time.png`

## Reproducibility notes

- Fixed random seed (`42`) across scripts where applicable.
- Pipelines are intended to fit preprocessing on training data before validation/test transforms.
- `test.csv` labels are never used (Kaggle test has no labels).
- Missing optional libraries/scripts are handled gracefully in `run_all.py` with clear notes.

## Main file guide

- `src/run_all.py`: runs the integrated model scripts (Logistic Regression, Random Forest, SVM, XGBoost, LightGBM by default), and builds `outputs/results_summary.csv`.
- `src/compare_models.py`: reads `results_summary.csv`, saves comparison table + plots.
- `src/train_*.py`: individual teammate model training/evaluation/submission scripts.
- `src/preprocessing.py`: shared preprocessing helpers.
- `src/metrics.py`: shared metric utilities.
- `src/utils.py`: repository-relative paths and I/O helpers.
